# 3Dモデル指示ツール

人の形の 3D モデルを動かして、演者さんや画像生成 AI にポーズや構図を伝えるための Web ツールです。
ブラウザだけで動き、インストールはいりません。

**使ってみる：** https://ishi061-svg.github.io/3d-model-tool/

## できること

- 1〜3人を出し、1人ずつ男性（青）・女性（赤）を選べる
- 人をクリックで選び、ドラッグで立ち位置を動かす。向きはスライダーで変える
- 人の高さ（上下）もスライダーで変えられる
- 9種類のポーズから選んで、そこから調整できる
- 関節の「つまみ」をドラッグして、頭・胸・腕・脚を曲げる
- 関節ごとに「前後・ひねり・横」の3本のスライダーで細かく調整する
- 手の形を、開く・握る・指さし・ピース・グッド・OK の6種類から選べる（左右別々）
- 椅子・テーブル・丸テーブルを置ける（ドラッグで移動、スライダーで向きを変える）
- 画像で保存（16:9・9:16・1:1、背景の色、床あり・なし、PNG・JPG）。保存される範囲は枠で表示
- ポーズを JSON ファイルで保存し、あとで読み込んで続きを作れる
- 今のポーズのまま、骨入りの 3D データ（glb）で書き出せる（Blender などで開ける）

## 使い方

- 画面の何もない所を左ドラッグ：カメラを回す
- ホイール：近づける・離す
- 右ドラッグ：カメラを横にずらす

## 使った技術

- HTML・CSS・JavaScript
- [Three.js](https://threejs.org/)（Web で 3D を表示する部品）
- Blender（素体の骨の結び付け・滑らかにする加工・glb への変換）
- Claude Code（AI と一緒に、1ステップずつ制作）

## 素体（3D モデル）について

どちらも利用規約を確かめたうえで、加工して使っています。書き出した glb ファイルの中にも、作者名と配布ページを書き込んでいます。

- 女性：「[【無料】MMD用女性素体（リグ付き）](https://booth.pm/ja/items/1958825)」射当ユウキ（プリメロ工房）
- 男性：「[ローポリ 男性 FBX素体](https://booth.pm/ja/items/3501696)」柚木零（柚木零の店）

素体の著作権は、それぞれの作者にあります。
